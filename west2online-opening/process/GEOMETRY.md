# 透明长方体：角度反算与修正

## 坐标与旋转顺序

采用面向纸面的正交视图：X 向右，Y 向下，Z 向纸面内部。初始长边沿 X、最短的高沿 Y，这两条边贴着纸面；中等长度的宽沿 Z，与纸面垂直。

先绕纸面的竖直轴 Y 转动，使长边的右端进入纸面；再绕纸面的水平轴 X 仰起，使已经进入纸面的右端在画面中上抬。这一解释同时保留现有尖括号的“长向上扬、短高竖直、外露厚度向右下”三组方向。它是与现有二维括号棱线匹配的**等效三维姿态**，原括号并没有保存独立的三维模型。

这里的第二步是空间仰起，不是在 SVG 中直接 `rotate(-20)`；后者会同时倾斜高度方向，无法匹配目前括号的竖直高度棱。

令向内转角为 θ，仰起角为 φ，先旋转再正交投影：

```text
Ry(θ) = [ cosθ   0  -sinθ ]
        [   0    1    0   ]
        [ sinθ   0   cosθ ]

Rx(φ) = [  1     0     0   ]
        [  0    cosφ  -sinφ]
        [  0    sinφ   cosφ]

R = Rx(φ) Ry(θ)

x_screen =  cosθ · X - sinθ · Z
y_screen = -sinφ sinθ · X + cosφ · Y - sinφ cosθ · Z
```

八个三维角点均由 `(±L/2, ±H/2, ±W/2)` 生成，全部使用同一个 R 投影。位置最后单独加上屏幕中心，不混进角度或顶点计算。

## 从现有尖括号反算

当前括号父组是 `skewY(-20)`，其长向在画面中向右上抬 20°。厚度面在局部 SVG 中由 `(68,66)` 挤出，经过错切后的实际屏幕方向是：

```text
d = (68, 66 - 68 tan20°)
  = (68, 41.250024...)
```

令长向上扬斜率 a、外露厚度向右下的斜率 b 为：

```text
a = tan20°
b = (66 - 68a) / 68

a = sinφ tanθ
b = sinφ cotθ

θ = atan(sqrt(a/b)) = 37.761222326°
φ = asin(sqrt(a·b)) = 28.026761635°
```

因此 **20° 是投影后的画面角度，不是三维偏转或仰起角度**。外露厚度在画面中的角度为 31.241754090°。

得到的旋转矩阵为：

```text
R ≈ [ 0.790569646   0.000000000  -0.612372138 ]
    [-0.287743819   0.882728216  -0.371475962 ]
    [ 0.540558165   0.469883918   0.697858133 ]
```

计算检查：`RᵀR` 与单位矩阵的最大偏差约 `1.11e-16`，`det(R) ≈ 1`。这确保三条原始轴仍保持三维正交，没有引入错切或扭转。

## 尺寸与位置

为避免本轮又改变用户准备自己调整的位置和尺寸，从旧投影的长度 880、宽度的横向投影 136、高度 28 反推出三维尺寸：

```text
L = 880 / cosθ ≈ 1113.121412
W = 136 / sinθ ≈  222.087178
H =  28 / cosφ ≈   31.719843
```

这些是工程中的任意几何单位，不是毫米。仍满足长 > 宽 > 高。重新投影后，外轮廓顶点与上一版一致；本次没有为了“显得变了”而任意改角度。原先轮廓的棱线方向可以对应这一合法长方体，主要视觉错误来自面叠加和明暗组织。

保留屏幕中心 `(605,1660.022228)`。现在只需修改正式 SVG 中 `connecting-plane` 的 `translate(x y)` 就能整体移动，内部顶点不用再算，也不要叠加第二次 `skewY`。

## 可见面与明暗

对六个面的法线应用同一个 R。观察者位于纸面外侧，朝 +Z 看；只有法线的 Z 分量为负的面朝向观察者。这一姿态下可见面恰好为：

- 顶面：A–B–C–D。
- 近侧长面：D–C–G–H。
- 左端面：A–D–H–E。

旧版额外绘制的右端面朝向背面，且其二维投影与近侧长面重叠。旧版“透明 → 中央亮橙 → 透明”渐变又在顶面制造了拱起或扭转的感觉。正式稿已移除这两项和远侧隐藏底边。

新稿按左上方光源的关系组织三个平面的浅、中、深色，每个平面采用均匀半透明填色。共享棱线连续，高亮只放在边缘，没有跨面或中央凸起式渐变。这是为画面可读性设计的玻璃感示意，不模拟折射。

## 复现

在工程根目录运行：

```powershell
node process/rebuild-slab.cjs --apply
npm.cmd run render
```

不带 `--apply` 的第一条命令只更新工程计算与独立几何 SVG，不修改主稿。详细的三维顶点、屏幕顶点、法线和矩阵见 `slab-geometry.json`。独立查看 `slab-projection.svg` 或 `../output/slab-projection.png` 可以排除其它透明薄片的视觉干扰。
