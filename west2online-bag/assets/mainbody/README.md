# WEST2ONLINE 四线格主体

**直接编辑 `mainbody.svg` 和 `mainbody.css`，然后运行 `npm run build`。** `build` 与 `render` 现在执行同一个导出流程，只读取编辑源，更新 `output/`，不会重写源 SVG 或从模板恢复文案。

参考本目录的 `image.png` 中间主体，先实现不带背景的基本版。用户原先给出的 `reference/style/image.png` 路径在当前目录中不存在，现存参考图位于本目录；原图保留不变。

主体为 **4 × 4** 网格，按从左到右、从上到下的顺序读出 **West2online**。`W` 为大写，其余字母为小写，使用同款等宽字体、同一字号；`W` 和 `2` 完整显示，`2` 使用 `#F99C1A`；`n/o` 统一保留上半部，`e` 保留右半部，`t` 的纵切线穿过竖干中心，`s/l/i` 保留原有的三分之二切分。切口与稿线对齐；每格包含上伸线、x 高度线、基线、下伸线，另有少量局部辅助线。其余五格放置小字和 Logo：

```text
W     e     s     t
小字  2     o     小字
n     l     小字  i
n     小字  e     Logo
```

画布为 `1008 × 1424`，单格为 `240 × 344`，四周留出 24 个 SVG 单位。SVG 与预览保留清晰的切字画面，最终 PNG 额外进行淡字形补全与波点渲染，所有交付文件均无背景。字形与稿线在 SVG 中为矢量，Logo 使用用户提供的原始 SVG 资产（该资产内部含嵌入式 PNG）。

| 字符位置 | 保留部分 | 保留的辨识特征 |
| --- | --- | --- |
| 第 1 行 `W` | 全部 | 大写完整字形，无切分线。 |
| 第 1 行 `e` | 右侧 1/2 | 横杠、右侧开口和弧线。 |
| 第 1 行 `s` | 上侧 2/3 | 上弧与中部转折。 |
| 第 1 行 `t` | 竖干右半侧 | 分割线仍在 `x=116.411`，字形向右移动 7.105，使切线穿过竖干中心。 |
| 第 2 行 `2` | 全部 | 完整字形，颜色 `#F99C1A`，无切分线。 |
| 第 2 行 `o` | 上侧 1/2 | 小写轮廓的中线为 `y=178.115`，与 `n` 同为横切一半。 |
| 第 3 行 `n` | 上侧 1/2 | 肩部与两侧竖干的起点。 |
| 第 3 行 `l` | 下侧 2/3 | 长竖干与底部弯钩。 |

第 3 行第 3 格、第二行第 4 格、第四行第 2 格的一行小字使用格内坐标 `x=8, y=183` 和 `.microcopy` 样式，文案直接在 SVG 中编辑。第 4 行第 4 格的 Logo 引用 `../icon/west2-online-logo.svg`，等比放入 `x=20, y=72, width=200, height=200` 的框内。

## 文件与编辑方式

| 文件 | 用途 |
| --- | --- |
| `mainbody.svg` | 可直接编辑的主体源文件，按行列分组，所有小字为 `<text>`。 |
| `mainbody.css` | 独立样式文件：颜色、稿线、透明度、小字字体和字号。 |
| `content.mjs` | 最初生成布局时的历史参考；构建不再读取此文件。 |
| `mainbody.mjs` | 只读源 SVG 的导出脚本；顶部 `halftone` 调整大字波点参数。 |
| `output/mainbody.svg` | 已内联样式与 Logo 的独立 SVG，保留清晰切字画面。 |
| `output/mainbody.png` | 大字淡补全 + 波点，稿线、小字和 Logo 保持清晰的透明 PNG，`2016 × 2848`。 |
| `output/mainbody-preview.png` | 保留原有清晰切字效果的透明预览，`1008 × 1424`。 |

**根目录的 `mainbody.svg` 是唯一的内容与布局编辑源，需要保留。** 它是 `build` / `render` 的输入；`output/mainbody.svg` 是导出副本，可独立查看，因为已内联 CSS 和 Logo。修改导出副本不会回写到源文件，下一次导出会覆盖该副本。

日常改小字：直接搜索 `mainbody.svg` 中的文案并编辑 `<text>`，然后运行 `npm run render`。可以单独修改每一个数字与每一行小字。源 SVG 用 XML stylesheet 引用同目录 CSS；在浏览器查看时保留两者的相对位置。在忽略外部 CSS 的矢量编辑器中，打开 `output/mainbody.svg`，其中的小字仍为文本。

改整体样式：编辑 `mainbody.css`。数字 `2` 的橙色由 `.letter-fragment.accent` 单独控制。源 SVG 中不重复写颜色、线宽、字号等外观样式，导出时才内联 CSS。

改字符布局：直接编辑 SVG 中的 `cell-r行-c列` 分组、字形引用及坐标。`content.mjs` 已不参与构建，不需要把 SVG 改动同步到另一个文件。导出脚本中已移除源 SVG 的生成与写回代码。

在 SVG 中直接调整切口：编辑 `<defs>` 下命名为 `visible-cell-N` 的裁剪矩形，并同步该格的 `.split-rule` 路径。每格只有一个 `.letter-fragment`，没有第二份错位字形，也没有用白色色块遮盖；被裁掉的部分保持透明。

Logo 在源 SVG 中保留可读的相对引用，原始资产不改写；导出时将该 SVG 的原始字节嵌入 `output/mainbody.svg`，保证交付文件可独立打开。

## 生成与导出

在本目录运行：

```powershell
npm install
npm run render
```

也可以使用完全等价的命令：

```powershell
npm run build
```

也可从仓库根目录运行，路径不受当前工作目录影响：

```powershell
node .\west2online-bag\assets\mainbody\mainbody.mjs
node .\west2online-bag\assets\mainbody\mainbody.mjs --scale 3
```

旧命令中的 `--build` 也兼容为只做导出，不会再重新生成源 SVG。`npm install` 只安装本目录的 `sharp` 及其依赖；不再需要 `fontkit` 或大字字体文件。导出文件全部写入本目录的 `output/`。

## 最终 PNG 的波点处理

`npm run render` 先按原流程生成清晰 SVG 和预览 PNG，然后单独处理最终 PNG：

1. 从当前编辑源提取两个 `e`、两个 `n`，以及 `s/t/o/l/i` 各一个的完整轮廓，共补全九个切字，在其深色切字下方叠加 6.5% 不透明度的淡字形。`W` 与 `2` 继续完整显示。这一步只发生在内存中的最终 PNG 分支，源 SVG 与预览不增加补全图形。
2. 分离“大字 + 淡补全”和“稿线 + 小字 + Logo”两层。只给大字层临时铺白，把淡字形的透明度转换成接近白色的 RGB 明暗，供波点算法计算网点面积。这样补全部分会成为稀疏小点，而不是一块低透明度实色。
3. 实际调用 `../bg/halftone.cjs`，只对大字层重建网点。脚本复用本子项目的 `sharp`，不修改背景脚本及其原有导出。
4. 取该脚本的透明油墨层 `image-halftone-ink.png`，再把未经过波点处理的稿线、小字和 Logo 叠回，输出 `output/mainbody.png`。这些细节保留平滑边缘和原始颜色；临时白底不进入最终文件，网点之间保持透明。

补全浓度在 `mainbody.css` 的 `.halftone-completion` 中调整。波点参数集中在 `mainbody.mjs` 顶部的 `halftone`：默认间距为 5.2 个 SVG 单位（2 倍导出时为 10.4 px），角度 45°，`gamma=1.1`，`dotScale=1`，`grain=0.018`，使用固定种子和原色模式。保留原来的墨点覆盖率，深色区域允许相连，以保持大字的视觉重量。改变 `--scale` 会同步放大网点间距，保持相对视觉尺度。

主体在 `../../logo_page.svg` 中缩放为 `0.64`，因此点距在最终画布中为 `5.2 × 0.64 = 3.328`，约 3.33 个画布单位（默认 2 倍成图中为 6.656 px）。抗锯齿采样 `samples=3` 保持不变，视觉疏密由 `spacing` 控制；网点大小仍随各处明暗变化。

数字 `2` 的源填色仍为 `#F99C1A`；最终 PNG 的明暗和颜色由网点颜色及覆盖面积共同表现。预览继续使用原来的平滑缩放导出，不经过波点脚本。

中间图片由 `mainbody.mjs` 在系统临时目录中为每次导出单独创建，成功或报错后自动清理；构建不读取或创建仓库内的 `tmp/` 目录。所需代码保留在本目录的 `mainbody.mjs` 和 `../bg/halftone.cjs`，无需保留旧缓存、检查图片或备份。最终交付仍只有 `output/` 中的三个文件。

## 字体与边界

当前大字轮廓最初从 **DejaVu Sans Mono Bold** 提取，采用统一字号和等宽排布，现已直接保存在源 SVG 中。导出使用这些现有轮廓，不再生成字形，也不执行字宽、字体、字数或边距检查。

切分和格内裁剪由 SVG 的 `<clipPath>` 控制，可以直接编辑。小字保持 `<text>`，使用 CSS 中的等宽字体栈；实际文案、坐标与布局以当前源 SVG 为准，导出不会恢复占位内容。
