# Slogan 页主体

`sloganbody.svg` 是标语内容的独立编辑源，画布为 1008 × 1424，背景透明。顶部为“我在西二”，底部为“为你在线”，其中“西二”和“在线”使用 `#F99C1A`。中部依次为 AI、前端、Java、Golang、Unity、设计、安卓。

上下两行各有四个 240 × 240 的等宽字格，左右距主体边缘 24。顶部字格位于 `y=24..264`，底部位于 `y=1160..1400`；外框及 `x=264、504、744` 三条竖向分格线从顶部连续连接到底部。文字统一采用 **思源宋体 Heavy（Source Han Serif SC，900 字重）**；上下标语字号为 236 px，每字按实际渲染轮廓居中，保留与稿线之间的小间隙。“二”等字保留字形本身的比例，不单独拉伸。

中部可用高度为 `1160 - 264 = 896`，七行各占 `896 / 7 = 128`。每行上下至少各留 10，字形下缘与稿线之间留 8，稿线宽 1，因而允许的最大字形高度为 `128 - 10 - 10 - 8 - 1 = 99`。实测统一字号 90 px 时，最高的 `Golang`、`Unity` 为 99；增至 91 px 时为 100，因此在这套留白条件下选用最大整数字号 **90 px**。

各组名按可见字形中心对齐垂直中线 `x=504`，文字与下方短稿线整体在各行中居中。组名字形中心的纵向间距为 128，目标中心高度依次为 `323.5、451.5、579.5、707.5、835.5、963.5、1091.5`；不同语言、大小写的字面高度不改变中心间距。稿线随各组字形下缘定位，以实际字形宽度为基础向左右各延长一个全角字宽（90 px），不会铺满整页。抗锯齿像素边界可能有半个 SVG 单位的取整差异。

本机使用已安装的 `C:\Users\17169\AppData\Local\Microsoft\Windows\Fonts\SourceHanSerifSC-Heavy.otf`，覆盖当前中文和英文文案。源 SVG 的字体回退为 `Noto Serif SC` 与系统衬线字体；在其他机器保持相同效果时，需使用相同的思源宋体 Heavy 字体。

文字均保留为可编辑的 `<text>`；字体、字号、颜色和稿线样式在源 SVG 的 `<style>` 中调整。修改字形或字体后，可微调各字的 `x`、`y`，保持可见轮廓与稿线的留白。

后续文字和图形在本文件中编辑。`../../slogan_page.svg` 通过 `sloganbody-art` 引用此文件，缩放到 64% 后居中放置；页面背景和半透明遮罩在页面 SVG 及 `../../styles/slogan_page.css` 中单独控制。

在 `west2online-bag` 目录运行：

```powershell
npm run build:slogan
```

页面导出脚本直接读取并内嵌当前的 `sloganbody.svg`，在 `../../output/slogan_page/origin/` 中生成 `slogan_page.svg`、`slogan_page.png` 和 `slogan_page-preview.png`，无需单独导出主体 PNG。两种 260 × 360 mm 印刷版由 `npm run build:print` 导出到对应的 `260x360mm_origin/` 和 `260x360mm_ink/` 文件夹。
